# PhonePe Digital Payments Analysis

## Project Overview

This project analyzes PhonePe digital payment data to understand transaction patterns, user adoption, app usage, transaction types, and district-level demographics.
The analysis focuses on identifying trends in digital payments, comparing transaction activity across different locations and time periods, and exploring the 
relationship between transaction volumes and demographic factors such as population density.
The project was performed using Python for data cleaning, exploratory data analysis, statistical analysis, and data visualization.
The findings provide insights into digital payment adoption and usage patterns.

## Business Problem

Digital payment platforms generate large volumes of transaction and user data across different states, districts, time periods, and transaction categories. 
However, raw data alone makes it difficult to understand user adoption patterns and identify the factors associated with higher transaction activity.

This project analyzes PhonePe digital payment data to answer the following questions:

- How have app usage and digital transactions changed over time?
- Which transaction types contribute the most to overall digital payment activity?
- How does transaction volume vary across different locations?
- Is there a relationship between population density and transaction volume?
- Which districts have the highest population and how can demographic factors help explain digital payment adoption?
- What patterns and insights can be identified from the available PhonePe transaction and user data?

## Project Objectives

- Analyze transaction volume and transaction value across different time periods and locations.
- Identify the most common and significant digital payment transaction types.
- Study app usage trends to understand changes in user adoption over time.
- Compare transaction activity across states and districts.
- Analyze district-level demographic data, including population and population density.
- Explore the relationship between population density and transaction volume.
- Perform data quality checks and exploratory data analysis to identify meaningful patterns.
- Generate actionable insights from PhonePe digital payment and user data.

## Dataset Information

This project uses PhonePe digital payment data containing information related to transactions, users, app usage, device brands, and district-level demographics.

The datasets were used to analyze:

- Transaction volume and transaction value
- Transaction types
- State-wise and district-wise transaction activity
- Registered users and app usage trends
- Device brand distribution
- District population and population density
- The relationship between demographic factors and digital payment activity

The data was explored, cleaned, validated, and analyzed using Python libraries such as Pandas and NumPy before creating visualizations.

## Analysis Performed

The project includes the following analyses:

### 1. Exploratory Data Analysis (EDA)
Performed data exploration, checked data types, missing values, duplicates, and summary statistics to understand the structure and quality of the datasets.

### 2. Transaction Analysis
Analyzed transaction volume and transaction value to identify patterns across different transaction types, states, and time periods.

### 3. App Usage Analysis
Analyzed registered users and app usage trends to understand changes in digital payment adoption over time.

### 4. Transaction Type Analysis
Compared different transaction categories to understand their distribution and contribution to overall transaction activity.

### 5. State and District-Level Analysis
Explored geographical variations in transaction activity and analyzed district-level demographic information.

### 6. Device Brand Analysis
Analyzed device brand data to understand the distribution of users across different mobile device brands.

### 7. Population and Transaction Analysis
Explored the relationship between district population, population density, and transaction volume.

### 8. Correlation Analysis
Performed correlation analysis to identify relationships between demographic factors and digital payment activity.

## Key Findings

- App usage showed an overall growth trend, indicating increasing adoption of digital payments over time.
- Transaction activity varied across different transaction categories, highlighting differences in how users utilize digital payment services.
- Transaction patterns differed across geographical locations, showing variation at the state and district levels.
- District-level demographic analysis highlighted differences in population and population density across locations.
- The correlation analysis was used to examine the relationship between transaction activity and demographic factors such as population density.
- Device brand analysis showed that PhonePe users were distributed across multiple mobile device brands.
